# 支援週予定メーカー

特別支援学級の担任向けに、週予定表づくりを時短するWebアプリです。
全国どの学校でも使えるよう、学校名の表題設定・サンプルデータ・写真取り込みに対応しています。
交流クラスの時間割をもとに、支援児童ごとの週予定・介助員の配置をまとめ、印刷・配布できます。

## 主な機能

- **交流クラスの時間割登録**：紙の時間割の写真からAIが読み取り（Gemini）／手入力
- **児童・介助員登録**：交流先・交流コマ、介助員の勤務不可コマ、配慮メモ
- **週予定の作成**：先週コピー、交流内容の自動引用・再反映、介助員の自動割付、欠席管理
- **出力**：児童別・全体一覧・交流クラス別・介助員別・クラス別・クラス×曜日一覧の印刷／PDF・Excel・Word保存
- **学校名設定**：印刷・出力の表題に学校名を表示
- **サンプルデータ**：トップページから1クリックで試用データを読み込み可能
- **バックアップ**：全データをJSONで保存・復元（機種変更・共有用）

## 使い方

### 起動
1. フォルダ内の **`start-app.cmd`** をダブルクリック
2. ブラウザが自動で `http://localhost:3001` を開きます
3. 終わるときは黒いウィンドウで **Ctrl+C**

### 週予定づくりの流れ
1. **交流クラス**：時間割の写真を取り込むか、手入力します（初回のみ）
2. **児童・介助員**：支援児童の交流先・交流コマ、介助員の勤務不可コマを登録します
3. **週予定**：週を作り、「介助員を自動割付」→セルを手修正します
4. **出力**：必要な表（児童別・全体一覧・交流クラス別）にチェックして印刷／PDF・Excel・Word保存します
5. 翌週は「先週コピー」で複写し、変更点だけ直します

### 写真取り込みを使う場合
`.env.local` の `GEMINI_API_KEY=` に Google AI Studio のキー（無料枠あり）を設定し、
アプリを再起動してください。キーなしでも手入力ですべて利用できます。
設定状態は「交流クラス」画面の写真ボタン横（利用可／未設定）で確認できます。
公開版（Vercel）ではダッシュボードの Environment Variables に `GEMINI_API_KEY` を設定し、再デプロイしてください。

## データについて
- 保存先はブラウザの **localStorage** のため、別の端末とは共有されません
- 通常の利用で児童名などのデータが外部送信されることはありません。ただし写真読み取りでは画像が Google の API に送信され、ファイル出力（PDF/Excel/Word）はサーバー側で生成されます
- 他の先生・別の端末に渡す場合は、トップページの「バックアップ保存／復元」をご利用ください（全データをJSONで受け渡し。復元時は現在の入力が上書きされます）

## 開発

```sh
npm install
npm test   # vitest
npm run lint
npm run build
npm run dev -- --port 3001
```

- 公開版（Vercel）は `main` ブランチへの push で自動デプロイされます
- 写真取り込みにはサーバーの `GEMINI_API_KEY`（Vercel は Environment Variables）が必要です

## 技術スタック
- Next.js（App Router）+ React + TypeScript + Tailwind CSS v4
- 時間割の写真読み取り：Gemini 画像理解（APIキーはサーバー側でのみ参照）
- PDF出力：pdfkit、日本語フォントは同梱の Noto Sans CJK JP（SIL Open Font License 1.1）を使用
